# Private Audio Overrides

Place personal local audio experiments here if needed.

Audio files in this folder are ignored by Git and are not project assets. Do not treat commercial soundtrack files placed here as distributable, bundled, or licensed GBLOCK content.

Supported experiment extensions currently ignored:

- `.mp3`
- `.wav`
- `.ogg`

The app does not load this folder yet. `GBLOCK-011` currently provides original tone-based placeholder cues only.

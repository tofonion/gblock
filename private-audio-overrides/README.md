# Private Audio Overrides

Place personal local audio experiments here if needed.

Audio files in this folder are ignored by Git and are not project assets. Do not treat commercial soundtrack files placed here as distributable, bundled, or licensed GBLOCKS content.

Supported experiment extensions currently ignored:

- `.mp3`
- `.wav`
- `.ogg`

The app does not load this folder yet. The app currently provides original tone-based placeholder cues only.
